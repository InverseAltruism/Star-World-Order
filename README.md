## 🚀 START GAME

### Prerequisites
- Node.js 18+
- A Web3 wallet (MetaMask, Trust Wallet, Phantom)
- A Star Skrumpey NFT (for DAO access)

### Installation

```bash
# Clone the repository
git clone https://github.com/InverseAltruism/Star-World-Order.git
cd Star-World-Order

# Install dependencies
npm install

# Set up environment
cp .env.example .env.local

# Start the dev server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) and insert the ★ cartridge! 

### Controls

| Command | Action |
|---------|--------|
| `npm run dev` | Start development server |
| `npm run build` | Build for production |
| `npm run start` | Start production server |
| `npm run type-check` | Run TypeScript checks |
